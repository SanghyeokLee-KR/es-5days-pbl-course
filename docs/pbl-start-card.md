# PBL 시작 카드

- 프로젝트 주제: 쇼핑몰 백엔드 log4j 로그 트러블슈팅 검색
- 사용자는 누구인가: 장애 신고를 받고 원인 로그를 찾아야 하는 백엔드 운영 담당자
- ES로 찾게 할 문서 1건은 무엇인가: log4j2 JSON Layout으로 남은 로그 이벤트 1건
- 사용자가 입력할 검색 질문 1: "시간 초과"를 메시지에서 검색한다.
- 사용자가 입력할 검색 질문 2: 결제 서비스의 ERROR 중 처리 시간이 3초를 넘은 로그를 찾는다.
- 사용자가 입력할 검색 질문 3: 서비스별 ERROR 수와 평균 처리 시간을 확인한다.
- 필터에 사용할 분류 field 후보: 서비스명, 로그 레벨, 예외 클래스
- 정렬에 사용할 숫자·날짜 field 후보: 발생 시각, 처리 시간
- Dashboard에서 답할 질문 1: 어느 서비스에서 ERROR가 몰리고, 어느 시간대에 늘어나는가?

## 범위 확인

- ES index, 검색 요청, 분석·Dashboard를 완성한다.
- 실제 이용자 정보와 실제 운영 로그는 사용하지 않는다.
- Day 2에 최소 5,000건의 합성 데이터를 만들 계획이다.
